# 改善メモ
- アイテム設定画面UIについて、
  - アイコンと名前だけのグリッド表示にする。押すと詳細が見れる(そこに装備するボタン)。
  - アイテムの種類はもっと増やす。
  - 持ち込みについては上部に枠が5個ぐらい表示されていて、ロックされている。ロックは条件達成で解除。最初はすべてロック。
  - アイテム自体は条件達成ではなくガチャで開放。未開放のものは？で表示されている。
- 総単語リスト画面について
  - 出題されるステージが判るようにする。
- バトルスタイルについて
  - 初期でも2個は選択肢があるようにする。
  - ホーム画面のところで、未開放は表示されないのではなく、ロック表示で表示するようにし、そのままダンジョンへ出発するとスタイルは何もない状態で出発することになる。
  - スタイルの解放条件は単語進捗によるものにする。
- ステージについて、
  - 次以上のステージは最初はロック状態にする。
  - ボスを倒せば次のステージを開放とする。
- クエストについて、クリアすると、報酬を受け取るボタンで受け取り→新しいクエストが出現する
- プレイ時について、発音は自動で流れるようにする。
- 自信度バーは問題ごとに最低にリセットされるのではなく、継続するようにする。
- 出題のところに　正答/出現回数　の情報が出るようにする。
- プレイ中いい感じのBGMが流れるようにしたい。攻撃時、ダメージ時、アイテム獲得、敵出現時、ボスの出現時、アイテムゲット時、クリティカル時、クリア時などなどのSEとかも
- 
- 敵を倒すごとに、ドロップとしてアイテム(解放されているものの中から出る)が取得できる形にする(3つの中から選ぶ)。(アイテムがどんどん増えていき自分のビルドを毎回のrunで形作っていく)
- アイテムにレアリティをつけ、Run中のドロップやガチャでの排出率に影響するようにする。
