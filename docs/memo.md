# 改善案メモ
- 5問ごとにスキル(HP回復・攻撃力増加・防御力増加・時間制限増加など)をランダム3択から選ぶ(モーダル)
  - 上記の変更に従って、ダメージ計算を攻撃力及び防御力を考慮したものに変更する。

- ダンジョンステージ分けして幅広いレベルに対応
  - 現在のを最終ステージとして、5段階にする
  - 最初のステージは、時間制限を現在の3倍、敵のHP1/5、ステージ数3としてそこから段階的に上げていく、コイン数はステージが上がるに従いインフレするようにする。

- ミスした時、次へを押すまで待つようにして、しっかりと解答や正解を確認できるように。(ここで一旦停止ができるようにする)

- 見切れてしまってスクロールする必要が出るので、収まるように敵画面のサイズ(足りなければ他のも)で調整する。スクロールしなくても全情報が見れるように

- ステージ数表示が小さくて見えないのでもう少し大きくわかりやすくする。
